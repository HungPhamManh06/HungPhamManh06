# Agent Skills installation

This directory contains the Addy Osmani `agent-skills` pack installed for this repository.

- Source: https://github.com/addyosmani/agent-skills
- Installed via: `npx skills add addyosmani/agent-skills --agent universal --skill '*' --yes --copy`
- Skills live in `.agents/skills/<skill-name>/SKILL.md`.
- Supplemental checklists live in `.agents/references/`.
- Specialist personas live in `.agents/agents/`.
- Upstream license is copied at `.agents/agent-skills-LICENSE`.

Use `skills-lock.json` to audit/update the installed skill hashes.
